# Portfolio notes

## Short CV version

**Studio Blocks — WordPress / React integration**  
Custom Gutenberg plugin built with PHP, React and TypeScript. Includes dynamic server-rendered content, a React form island, custom REST API, TanStack Query, React Hook Form, Zod validation, accessibility, i18n and GitHub Actions.

## Recruiter summary

Studio Blocks demonstrates that the React skills shown in my application projects also translate into a CMS environment. Instead of treating WordPress as a page builder, the project uses custom block development, typed React editor code, PHP rendering, custom content types and a REST integration.

## Requirements covered

- WordPress custom development;
- Gutenberg block development;
- React + TypeScript inside WordPress;
- PHP ↔ React integration;
- custom WordPress REST API;
- TanStack Query;
- React Hook Form + Zod;
- semantic HTML and accessibility;
- i18n / translation-ready UI;
- GitHub Actions;
- Docker-based local environment.
